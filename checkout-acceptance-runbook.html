八轮验收

A · 入口与编辑器

Checkout 独立环境、页面/模板选择、固定骨架、组件区域、Save/Discard/Publish。

B · 核心买家交易

游客/登录、地址、运费、支付、Billing address、CTA 与错误定位。

C · 金额与订单摘要

商品、优惠、运费、税费、Booster 与 PC/M 多处 Total 的一致性。

D · Commerce boosters

Product upsell、Shipping Insurance、VIP Club 的交易联动和失败回滚。

E · 内容与信任

10 个静态增强组件的添加、位置、空态、移动端和内容合规。

F · Checkout settings

7 组独立设置、边界值、继承优先级和 Online Store 隔离。

G · 响应式与无障碍

Desktop、390px、真机、键盘、焦点、触控面积和 200% Zoom。

H · 异常、安全、兼容

失败恢复、敏感支付信息、XSS/CSS 隔离、接口乱序和历史配置。

上线门槛

  • 全部 Blocker / P0 通过；P1 有 owner、修复日期及书面豁免。
  • 金额矩阵逐分一致，无旧 Quote 覆盖、旧价支付或负数 Total。
  • Save 与 Publish 隔离，无草稿污染线上或修改丢失。
  • Desktop 与 390px 真机都能完成一次真实测试支付。
  • 无重复订单/扣款、支付敏感信息泄漏、XSS 或支付区域样式覆盖。
  • 所有会影响 Pass/Fail 的 PRD 歧义已形成书面决定。

固定种子数据

  • 买家：游客；已登录且有 2 个保存地址。
  • 商品：单规格、多变体、Bundle、订阅、售罄、下架、缺图各 1 个。
  • 配送：单一方式、免费+付费两种方式、不可配送地址。
  • 优惠：WELCOME10、SAVE10，以及无效、不适用、接口失败码。
  • 支付：成功、拒付、超时、3DS/跳转型测试方式。
  • Booster：Upsell 多变体、Insurance $3.95、VIP $29.99。
  • 内容：空/超长/Emoji/CJK 文案、有效/404 图片、合法/非法 URL。

开始前资料

  • Build / commit / API / 订单计算服务版本与环境 URL。
  • 真实测试支付环境、支付方式和脱敏规则。
  • 固定 Quote 矩阵及每一步预期金额。
  • 已发布基线 + 独立验收草稿，禁止直接改生产店。
  • 本期不做项、已知限制和待拍板项的书面结论。
  • 匿名无痕窗口、Safari/iOS 与 Android 真机。

每个可添加组件统一九步

添加 → 修改核心字段 → 触发条件字段 → 拖入允许/禁止区域 → 验空值与失效资源 → 切 Mobile → Save 刷新 → 隐藏/删除/恢复 → Publish 后到匿名 Checkout 核对。

以下问题不拍板，就没有统一 Pass/Fail 标准 “原型当前如此”不等于 PRD 已自动变更。请在正式验收前为每项记录 Accept / Fix / Defer。
